# Двоичные деревья поиска

### A. Реализация двоичного дерева поиска

Реализуйте двоичное дерево поиска, поддерживающее операции добавления, удаления, поиска и печати. Вершина с двумя детьми при удалении заменяется максимумом левого поддерева.

Команды:
- `ADD n` — добавить число n. Выведите `DONE`, если число добавлено, и `ALREADY`, если оно уже есть в дереве.
- `DELETE n` — удалить число n. Выведите `DONE`, если число удалено, и `CANNOT`, если его нет в дереве.
- `SEARCH n` — выведите `YES`, если число есть в дереве, и `NO` в противном случае.
- `PRINTTREE` — напечатайте дерево в порядке левое поддерево — вершина — правое поддерево, при этом перед числом в каждой строке ставится столько точек, какова глубина вершины (корень — 0 точек).

Входные данные: Последовательность команд, по одной в строке.

Выходные данные: Результаты выполнения команд в порядке их поступления.

### K. Ближайшее не меньшее

Изначально множество целых чисел пусто. Требуется обработать N запросов двух типов:
- `+ i` — добавить в множество число i. Если непосредственно перед этим выполнялся запрос `?`, то добавляется число (i + y) mod 10⁹, где y — ответ на этот предыдущий запрос.
- `? i` — найти минимальное число в множестве, которое не меньше i. Если такого числа нет, ответ равен −1.

Входные данные: В первой строке записано число запросов N. Далее следуют N строк, каждая — запрос в формате `+ i` или `? i`.

Выходные данные: Для каждого запроса `?` выведите ответ в отдельной строке.
