# Лабораторная работа 2. Бинарный поиск

Курс: АиСД_РГРТУ, тема 2 «Бинарный поиск».

## Задачи

| Буква | Название | Идея решения | Решение |
| --- | --- | --- | --- |
| A | Двоичный поиск | Классический бинарный поиск числа в отсортированном массиве. Для каждого из `K` чисел выводим `YES` или `NO` | [A.cpp](A.cpp) |
| B | Приближённый двоичный поиск | Ищем ближайшее к запросу число в массиве (`lower_bound`, затем сравниваем соседей). При равенстве расстояний выводим меньшее | [B.cpp](B.cpp) |
| C | Квадратный корень и квадратный квадрат | Функция `x² + √x` монотонно возрастает, поэтому бинарный поиск по вещественному `x` на отрезке `[0, 10⁵]` | [C.cpp](C.cpp) |
| D | Корень кубического уравнения | Если `a < 0`, меняем знаки всех коэффициентов. Бинарный поиск по `x` на отрезке `[-2000, 2000]` по знаку `f(x)` | [D.py](D.py) |
| E | Коровы — в стойла | Бинарный поиск по ответу (минимальное расстояние). Проверка `can(d)` — жадная расстановка | [E.cpp](E.cpp) |

## Ограничения и особенности

| Задача | Особенности |

| A | Время 4 сек, память 64 MiB. `N, K ≤ 100 000`, элементы по модулю ≤ 10⁹ |
| B | `N, K ≤ 100 000`, элементы по модулю ≤ 2·10⁹ (нужен `long long`) |
| C | Время 1 сек, память 64 MiB. `1 ≤ C ≤ 10¹⁰`, точность не менее 6 знаков |
| D | Время 1 сек, память 64 MiB. Вывод с точностью не менее 4 знаков |
| E | Время 1 сек, память 64 MiB. `N < 10001`, координаты ≤ 10⁹ |
| F | `N ≤ 2·10⁸`, `x, y ≤ 10`. Верхняя граница поиска `N · min(x, y)` |
| G | `N, K ≤ 10001`, длины до 10⁷ см. Сумму кусков считаем с ранним выходом |
| H | `w, h, n ≤ 10⁹`. Ответ до ~3,2·10¹³, нужен `long long` |

## Общие шаблоны

**Бинарный поиск по ответу (целые числа).** `l` всегда допустимо, `r` всегда недопустимо:

```cpp
while (r - l > 1) {
    long long m = l + (r - l) / 2;
    if (can(m)) l = m;
    else r = m;
}
```

**Бинарный поиск по вещественным числам.** Фиксированное число итераций вместо сравнения с `eps`:

```cpp
for (int i = 0; i < 100; i++) {
    double m = (l + r) / 2;
    if (f(m) < 0) l = m;
    else r = m;
}
```
